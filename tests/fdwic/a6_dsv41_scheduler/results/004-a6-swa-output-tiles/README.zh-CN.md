# 阶段 004　A6 单卡 SWA 的 O-B、HC post 与补零分片

**以 003 的 319.060 µs 核窗口、406.690 µs Device wall 为对照。** 先分别改最后两个任务，判断哪一个能压缩 SWA 尾部，再看两项组合的整层收益。所有 004 配置均沿用 t17 的 54 个 V block、t20 的 54 组 1C1V。补零另设单项对照。[003 结果](../003-a6-swa-blocks/README.zh-CN.md) · [指标 JSON](metrics.json)

## 两个尾部任务

**t27 HC post（`post54`）**。原来 54 颗 V 核执行 64 个 block。00 的代表轮在两批之间有 35.702 µs 全卡无计算。固定输入的 80 行按列各分两半，共 160 个 chunk。新核每次处理一个 chunk 的全部 4 路输出，按 block 编号以 54 为步长领取 chunk。52 个 block 各算 3 个，2 个各算 2 个；每个 chunk 的输入和系数只需在本次调用中读取一次。末尾 10 次单独下发随之省去，最忙 block 的核体时长和整层收益用上板数据衡量。[HC post 入口](../../../dsv41_scheduler/kernels/pypto_lib_latest/vendor/external/hc_post.cpp)

**t21 O-B（`ob54`）**。原来每块矩阵为 80 行 × 160 列，32 个 C block 算完 5120 列。新核把前 4992 列切成 52 块 × 96 列，余下 128 列切成 2 块 × 64 列。54 个 C block 各有一块独立输出，起始列均按 32 对齐，列方向无需额外归约。块变窄后每核乘加量下降，但会有更多核读取同一份左矩阵；以 t21 首末跨度和 L0 实测判断。[O-B 入口](../../../dsv41_scheduler/kernels/pypto_lib_latest/vendor/external/o_proj_b.cpp)

## 其余任务筛查

按 003 的 16 个计算任务逐项检查了 block 数、核类型和输入形状。除 t27 之外，**唯一一个同类型 block 数超过 54 的任务是 t1 补零**。另外两项虽然未超核数，但一个 block 内仍可能有多块工作。

| 任务 | 固定输入上的分工 | 本阶段处理 |
| ---- | ---------------- | ---------- |
| t1 补零 | 原 80 个 V block 按行号运行，只有行 72–79 会写数据；前 72 个仍有核调用 | 独立 `padding8` 配置用 8 个 block 直达这 8 行，复用原清零实现。[补零核](../../../dsv41_scheduler/kernels/pypto_lib_latest/vendor/aiv/decode_sp_zero_padding.cpp) |
| t4 QKV 量化 | 5 个行组 × 20 个列块 = 100 个工作块，32 个 V block 各做 3–4 个 | 有条件试 50 个 V block 各做两块；需看缩短核体能否抵消新增的 18 次下发。[量化核](../../../dsv41_scheduler/kernels/pypto_lib_latest/vendor/external/qkv_quant.cpp) |
| t10 Q-B | C 侧处理 32768／256 = 128 个列块，32 组每组四块；V 侧只为有 RoPE 尾部的列块协作 | 调组数会改变每组循环次数和 C/V 握手，宜单独分析。[C/V 分工](../../../dsv41_scheduler/kernels/pypto_lib_latest/vendor/external/q_lora_projection.hpp) |
| t14、t17、t20 | t14 用 48 组同步启动的 MIX，t17、t20 已在 003 调为 54 | 保留 003 配置。要核对 t20 的回退，另跑已有的 `quant54`，与 003 只差 t20 的 32／54 组 |
| t0、t8、t9、t11、t12、t23、t25、t26 | 各任务 4–20 个 block，均能在一批内容纳 | 没有观察到超出核数造成的第二批。改变切块需要另看各核有效工作量 |

## 离线核对

四个候选包与 003 对照包都已编译、链接并组装，每包 19 个核、16 个计算任务。逐项对比 2735 条计划记录与逐核机器码指纹，只改中了各配置指定的 block 数及目标核。用 Host 执行新核入口的分配逻辑，将计算替换为写入计数，核对了 O-B 的 5120 列、HC post 的 160 × 4 路输出、补零的 8 行各覆盖一次。重建的 A5 和 A6 的 003 对照各自与原包 plan、19 份机器码和 callable 逐项相同。A6 数值输出与性能留待设备测量。
