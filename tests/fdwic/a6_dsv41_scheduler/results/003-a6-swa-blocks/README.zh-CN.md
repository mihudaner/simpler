# 阶段 003　A6 单卡 SWA 输出量化与输出投影分片

**本阶段只测一组新配置**：在合并后的 HBG 上同时启用 t17 输出量化和 t20 O-A 投影的 54 组分片（`--a6-plan quant54-oa54`）。用阶段 00 衡量从迁移起点到现在的累计变化，用阶段 002 已有的 GM-FAA 数据对照本次分片调整。

## 两处调整

- **t17 输出量化**有 64 个 tile。原计划提交 64 个 V block，A6 有 54 个 V，至少 10 个 block 要再次领取。改为 54 个 block 后，44 个各处理一个 tile，10 个在一次调用内各处理两个。阶段 00 的 L3 代表轮中，两批之间有 15.660 µs 全卡无核体执行。
- **t20 输出投影 O-A**也有 64 个 tile。原来 32 组 1C1V 各处理两个；改为 54 组后，44 组各处理一个，10 组各处理两个。t21 O-B 只有 32 个 160 列 tile，继续使用 32 个 C block。[基线分析](../00-baseline/README.zh-CN.md)

组合配置有 604 个执行实例。三种计划的 2735 条记录已逐项核对，只有指定的 block 数发生变化，19 个核与 callable 一致。A5 继续使用 578 个实例，计划、核及 callable 与阶段 001 一致。[指标 JSON](metrics.json)

## 测量与回填

按[单卡复测命令](../../doc/a6-environment.zh-CN.md#已有性能数据的复测方法)构建 `quant54-oa54`。L0 预热 1 轮、正式 10 轮，核对 30 个可写缓冲区，将核窗口与 Device wall 的算术均值填入 003 行。L3 用于拆解同一配置，`performance.py --level 3` 会给出 `t17_kernel_span` 和 `t20_kernel_span`。

`quant54`（t17 为 54、t20 为 32，共 560 个实例）保留给需要单独拆分 t20 贡献的实验。
