# 005　A5 迁移版 SWA 单卡性能与 L2 调度开销

**A5 迁移版每轮执行业务核 632 次，25 份输出参考全部通过。** 同一套四核 C++ 实现在 L0 的核窗口为 **156.759 µs**，开启 L2 后为 **168.817 µs**。当前迁移版各项实测均来自同一提交、同一张 A5、同一回放包，每个采集等级独立预热 1 轮、正式测量 10 轮。A6 五分块配置尚无整图实测结果，表中空白为待测项。[A6 问题定位](issues.zh-CN.md)

## A5 与 A6 的算子和分块

两端使用同一份输入、25 份参考和 19 个活跃核的源码。HC collapse、QKV 量化、norm/RoPE 和 Sinkhorn 均选设备 C++ 实现，绕过 PyPTO `pl.reg_scope()` 导出的独立 VF helper；C++ 仍使用向量作用域和寄存器。两端各自编译本平台的机器码。A5 使用 32 组 1C2V，A6 使用 54 组 1C1V。下表列出两份当前计划中全部六项分块调整。

## 复现本次 A5 测量

从迁移版实测提交 `a78b680908bc` 使用 CANN 9.3.0 和仓库 `pto_isa.pin` 构建 A5 HBG DFX 运行库及回放包，选择 `--platform a5 --kernel-set cpp`，保留 A5 原分块。单卡分配一次，三组均使用同一设备、同一 runner 和同一回放包。每级传给 native runner 的尾部参数分别为 `0 1 10`、`1 1 10`、`2 1 10`（等级、预热数、正式轮数），均使用 `--runtime=host_build_graph` 并关闭额外 AICPU 生命周期细分。使用 `performance.py --platform a5 --shared-device-clock` 汇总各级数据，L2 加 `--trace` 导出代表轮；L1 的 rank0 交给 `sync_bound.py` 计算下界。[构建与运行](../../doc/usage.zh-CN.md) · [性能统计](../../performance.py)
